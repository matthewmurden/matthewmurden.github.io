// algorithmic trading system

Seven-Pillar BTC Trader

An automated BTCUSDT perpetual futures system where each job a human trader does is its own pillar. Every minute the decision passes down a production line, and any pillar can veto the trade.

  • Entry, exit and regime models blend hand-written rules with LightGBM classifiers, so no single input can sink a decision.
  • Validated with walk-forward testing (test months hidden from tuning, fresh state each fold), a look-ahead leak test and fee/slippage stress tests.
  • Runs live on the Binance demo account with limit-first execution, protective take-profit/stop-loss orders and a kill switch; the live loop runs in about 4s per minute.
